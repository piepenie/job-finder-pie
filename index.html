소개

현장 데이터 이해와 시스템 구현의 연결점

학업 배경

지구시스템과학부 해양학 전공

자연 환경의 방대한 변수와 시계열 관측 데이터를 다루며, 오차와 노이즈를 꼼꼼히 점검하는 습관을 길렀습니다.

관심 영역: 해양학 관측·분석 감각
기술 전환

웹 백엔드 개발 역량

해양 데이터를 다루며 체감한 정합성의 중요성을 바탕으로, 백엔드 과정에서 대용량 데이터를 지연 없이 적재하고 안정적으로 전달하는 시스템 구조에 집중해 왔습니다.

관심 영역: 웹개발 & 데이터 파이프라인

역량

제조지능화 현장에서 발휘할 두 가지 핵심 역량

도메인 & 관측 감각 해양환경기사 보유

해양학 기반 데이터 감각

연속적인 환경 변화와 센서 데이터의 이상 징후를 놓치지 않고, "뒤를 돌아보며" 검증하는 끈기 있는 분석 태도.

공인 자격 및 역량 키워드
국가기술자격 해양환경기사 정량 계측·시계열 데이터 이상치 점검 데이터 신뢰성 검증
구현 & 엔지니어링 과정 수료

백엔드 시스템 구축

Java와 Spring Boot 환경에서 트랜잭션의 정합성을 보장하고, MySQL·Redis를 연계하여 데이터 병목을 방지하는 API 서버 구현 역량.

핵심 기술 스택
Framework
Java Spring Boot
DB & Cache
MySQL JPA Redis
API & Tool
RESTful API Git/GitHub Docker
